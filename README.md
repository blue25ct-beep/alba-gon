# 🏪 편의점 통합 자동발주 시스템 (V2)

점장님의 편의점 재고 및 발주 업무를 자동화하는 완벽한 클라우드 통합 시스템입니다!
기존 유앤미24(상온/냉장) 발주는 물론, **생필체인(주류)** 발주까지 하나의 시스템에서 완벽하게 분리하여 자동으로 처리합니다.

---

## ✨ V2 핵심 기능 요약

1. **상온/주류 완벽 분리 자동 발주**
   - 상온 상품을 스캔하면 유앤미24로, 주류 상품을 스캔하면 생필체인으로 똑똑하게 분리되어 발주 목록에 담깁니다.
   - 점장님 관리 화면에서도 상온과 주류 탭이 완벽히 나뉘어 있어, 섞이지 않고 안전하게 발주할 수 있습니다.

2. **목표 재고(안전 재고) 일괄 관리**
   - 관리자 화면의 **[목표 재고]** 버튼을 통해 전체 1,700여 개 상품의 목표 재고와 최소 발주 단위를 언제든 손쉽게 수정할 수 있습니다.
   - 기본 목표 재고는 1개로 깔끔하게 세팅되어 있습니다.

3. **장소 제약 없는 클라우드 원격 발주 (IP 주소/공유기 설정 필요 없음!)**
   - 매장 PC에 로봇 프로그램만 켜두시면, 점장님은 집이든 지하철이든 폰으로 사이트에 접속해 [발주하기] 버튼 하나만 누르면 끝입니다!
   - 0.1초 만에 매장 PC로 신호가 날아가, 로봇이 혼자 유앤미와 생필체인 사이트에 로그인하고 장바구니에 쏙쏙 담아줍니다.

---

## 🚀 딱 2단계! 아주 쉬운 시작 방법

### [1단계] 처음 한 번만! 프로그램 설치하기
1. `[처음한번]프로그램설치.bat` 파일을 더블클릭합니다.
2. 검은 창이 뜨면서 프로그램 구동에 필요한 부품들을 알아서 척척 설치해 줍니다.
3. 설치가 끝나면 **`.env`** (메모장) 파일이 자동으로 열립니다. 여기에 점장님의 진짜 유앤미/생필체인 아이디와 비밀번호를 적고 저장(Ctrl+S)해 주세요!
   *(이 정보는 매장 PC에만 안전하게 보관되며 절대 외부로 유출되지 않습니다.)*

### [2단계] 매일 출근해서 해야 할 일 (실행기 켜두기)
1. 매일 매장 카운터 PC를 켤 때, 폴더 안의 **`[필수]자동발주봇_실행기.bat`** 파일을 더블클릭합니다.
2. 검은 창이 하나 켜집니다. **이 창을 끄지 마시고, 최소화(창 내리기) 해두시면 됩니다.**
3. 이제 끝입니다! 로봇이 신호를 받을 준비를 완료했습니다.

## 📱 스마트폰(웹사이트) 사용 방법

1. 스마트폰으로 **https://blue25ct-beep.github.io/alba-gon/** 에 접속합니다.
2. **[알바생] 빠른 바코드 스캔 / 입력:**
   - 바코드 뒤 4~5자리(예: 60205)나 상품명 일부를 치면 실시간으로 상품이 검색됩니다.
   - 재고를 입력하고 저장합니다. (상온인지 주류인지 폰이 알아서 척척 분류합니다!)
3. **[점장님] 원격 통합 발주:**
   - 폰 화면의 톱니바퀴 아이콘을 눌러 **[점장님 관리 대시보드]**로 들어갑니다. (기본 비밀번호: 1234)
   - [상온] 탭과 [주류] 탭을 눌러 스캔된 내역과 추천 발주 수량을 확인합니다.
   - 수량을 살짝 조절하신 뒤, **[발주하기]** 버튼을 꾹 누릅니다!
   - 매장 PC의 로봇이 0.1초 만에 깨어나 자동으로 유앤미/생필체인 장바구니에 담아줍니다.
4. 나중에 유앤미/생필체인 공식 사이트에 접속해서 금액을 확인하시고 최종 **[주문 확정]**만 눌러주시면 끝!

## ❓ 자주 묻는 질문 (FAQ)

### Q1. 퇴근 후 집(LTE/5G)에서 발주 버튼을 눌러도 되나요?
**A. 100% 가능합니다!** 보안 클라우드를 통해 0.1초 만에 매장 PC로 신호가 날아갑니다.

### Q2. 폰에 뭘 깔아야 하나요?
**A. 아무것도 깔 필요 없습니다!** 그냥 인터넷 주소(github.io)를 즐겨찾기 해두고 일반 앱처럼 쓰시면 됩니다.

### Q3. 매장 PC가 꺼져 있으면 어떻게 되나요?
**A. 로봇이 잠들어버립니다.** 로봇이 장바구니에 물건을 대신 담아주려면, 반드시 매장 카운터 PC가 켜져 있어야 하고 `[필수]자동발주봇_실행기.bat` 창이 켜져 있어야 합니다!
